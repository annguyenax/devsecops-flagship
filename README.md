\#devsecops-flagship
A DevSecOps pipeline built around a real web application : a furniture e-commerce platform, originally developed as the coursework project \[Furniture-Web](https://github.com/annguyenax/Furniture-Web).
Goas: ship the app through an automated pipeline that catches security problem before they reach production.

##Planned stack

-App:React(Vite), Node.js/Express, MySQL

\-Docker, Docker compose, Nginx
-CI/CD: GitHub Actions
-Security gates: Gitleaks(secrets), Semgrep(code), Trivy(dependencies, images), 
-Infrastructure: Terraform on AWS, Kubernetes basics
-Observability: logging and monitoring

## Roadmap
